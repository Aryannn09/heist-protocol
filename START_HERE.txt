HEIST PROTOCOL — PROJECT PACKAGE

1. Extract the ZIP to a normal folder.
2. Install Node.js 22 or newer if needed.
3. On Windows, double-click RUN_GAME.bat.
   Alternatively, open a terminal in this folder and run: npm run dev
4. Open http://localhost:8787 in a normal browser and an Incognito window.
5. Create a room in the first window, join in the second, and mark both ready.

No dependency installation or API key is needed for local play.

Tests: npm test
Build: npm run build

The source, lockfile, Cloudflare Worker, Durable Object configuration, and
deployment instructions are included. Read README.md before publishing.
This is a source package, not a Netlify Drop upload. It has not been published.

Verification: eight automated tests passed, including a simulated five-round
game and rematch. A Cloudflare dry run passed in the previous build session.
Browser visual QA and live Cloudflare multiplayer testing remain outstanding.

Local rooms reset when the server stops. Production rooms use durable storage.
Frontend: plain JavaScript. State synchronization: one-second polling.
